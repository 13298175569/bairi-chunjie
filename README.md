# 百日純潔 · 生活自述

一个手机优先的个人生活打卡网页。认真吃饭，读几页书，再制造一点生活。

- 自填姓名、IP 属地，从第一天开始百日记录。
- 每天早餐、午餐、晚餐各一张图片，生成个人自述文章。
- 记录书名与阅读页数，生成《制造XXX》精装书封面。
- 月历通过三色圆点呈现活动，支持查看历史日期。
- 数据和图片仅保存在每位访问者自己的浏览器 IndexedDB 中，支持 JSON 备份和导入；不自动跨设备同步。

## 部署

纯静态站，无构建依赖。网站文件位于仓库根目录。

GitHub Pages：在仓库 Settings → Pages 选择 Deploy from a branch，分支选择 main、目录选择根目录。保存后 GitHub Pages 将自动发布根目录中的网站文件。

本地预览：使用任意静态 HTTP 服务打开仓库根目录。请勿依赖直接打开 `file://` 的存储行为。

网站趣味来自个人日常记录文化，与任何真实人物或其账号无关联。
